# Polska Wataha: lokalizacja dziecka

Rodzic/opiekun może widzieć bieżącą pozycję dziecka tylko przez aktywny Family Bridge.

Warunki:
- aktywne sparowanie parent_link,
- włączone udostępnianie lokalizacji,
- backendowa kontrola uprawnień,
- brak publicznego endpointu,
- brak dostępu administratora bez relacji rodzic-dziecko,
- widoczny czas ostatniej pozycji i dokładność,
- oznaczenie pozycji jako nieaktualnej po przekroczeniu limitu czasu.

UI rodzica:
- karta dziecka,
- „Pokaż na mapie”,
- „Ostatnia aktualizacja: ...”,
- „Dokładność: ... m”,
- status online/offline.

Młoda Wataha:
- widoczny status udostępniania,
- osobna zgoda na pracę w tle,
- możliwość wyłączenia udostępniania zgodnie z polityką rodzinną,
- SOS może przesłać bieżącą pozycję.

Nie implementować ukrytego stalkingu ani publicznego śledzenia.
