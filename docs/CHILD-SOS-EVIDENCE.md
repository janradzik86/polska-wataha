# Polska Wataha: materiał dźwiękowy z SOS dziecka

Polska Wataha może odebrać materiał zabezpieczony przez Młodą Watahę po świadomym użyciu przycisku SOS przez dziecko.

Zasady:
- tylko aktywnie sparowany rodzic/opiekun,
- brak publicznego linku,
- ADMIN nie ma dostępu tylko dlatego, że jest ADMIN,
- rodzic widzi czas, pozycję, dokładność GPS i sumę SHA-256,
- nagranie nie jest automatycznie przekazywane policji,
- eksport do służb wymaga świadomego działania rodzica/opiekuna,
- pozycja i dźwięk są przechowywane możliwie krótko.

UI rodzica:
- karta SOS,
- „Odtwórz zapis dźwięku”,
- „Pokaż miejsce na mapie”,
- „Nawiguj do ostatniej pozycji”,
- „Eksportuj kopię dla służb”,
- widoczna suma integralności pliku.

Nie implementować stałego podsłuchu, ukrytego nasłuchu ani nagrywania mikrofonu przed SOS.
